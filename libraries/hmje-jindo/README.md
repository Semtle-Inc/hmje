# hmje-jindo — 터미널 진행 표시

반복문의 진행 수식어와 함수 API를 통해 진행 막대를 표시합니다. 진행 출력은 표준오류(stderr)로 보내므로 표준출력의 프로그램 결과와 분리됩니다.

## 사용

HMJE 1.0.0-beta.1 툴체인의 SDK에 포함됩니다. 소비 프로젝트의 모듈에 사용할 라이브러리를 의존성으로 선언하고, HMJE 소스에서 모듈을 가져옵니다. 내보내는 모듈은 HmjeJindo입니다.

```hmjep
모듈 App의
    원본 경로는 "Sources/App"이고,
    의존 라이브러리는 HmjeJindo이다.
```

```hmje
HmjeJindo를 가져온다.
```

프로젝트·산출물의 전체 구성은 [프로젝트 명세](../../docs/project.md), 이 트리에서 SDK를 빌드·설치하는 절차는 [소스 빌드](../../docs/building.md)를 참고하십시오.

## 기능

| 구분 | 제공 내용 |
| --- | --- |
| 반복 수식어 | 진행을 보이며·표를 달아 진행을 보이며·모양을 잡아 진행을 보이며 |
| 함수 API | 진도시작·진도갱신·진도더하기·진도마침 |
| 표시 제어 | 전체 수량·이름·단위·폭과 출력 간격 |

## 지원 범위와 사용 조건

기본 막대 폭은 30칸, 최대 200칸이며 최소 갱신 간격은 100ms입니다. 진도상태는 값 타입으로 갱신 함수가 반환한 상태를 보관해야 합니다. stderr를 파일로 리다이렉트하면 진행 출력도 그 파일에 기록됩니다. 화면 앱에서는 UI 진행 표시를 별도로 구성합니다.
