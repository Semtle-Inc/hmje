# hmje-syntax — HMJE 구문 강조

HMJE 원문의 줄·낱말을 분류하여 편집기에서 사용할 강조 정보를 생성합니다. UI 모듈에 의존하지 않아 각 편집기의 색상·표시 정책에 연결할 수 있습니다.

## 사용

HMJE 1.0.0-beta.1 툴체인의 SDK에 포함됩니다. 소비 프로젝트의 모듈에 사용할 라이브러리를 의존성으로 선언하고, HMJE 소스에서 모듈을 가져옵니다. 내보내는 모듈은 HmjeSyntax입니다.

```hmjep
모듈 App의
    원본 경로는 "Sources/App"이고,
    의존 라이브러리는 HmjeSyntax이다.
```

```hmje
HmjeSyntax를 가져온다.
```

프로젝트·산출물의 전체 구성은 [프로젝트 명세](../../docs/project.md), 이 트리에서 SDK를 빌드·설치하는 절차는 [소스 빌드](../../docs/building.md)를 참고하십시오.

## 기능

| 구분 | 제공 내용 |
| --- | --- |
| 전체 강조 | 글강조·원본강조 |
| 변경 반영 | 글강조갱신 |
| 줄과 조각 | 글줄들·강조줄·코드조각 |
| 분류 | 선언·제어·타입·문자열·주석 등 낱말 종류 |

## 지원 범위와 사용 조건

구문 강조를 위한 어휘 분류 기능입니다. 프로그램의 문법적 유효성·타입·실행 가능성을 판정하려면 컴파일러의 진단을 사용합니다. 강조 결과의 색상과 글꼴은 호출자가 정합니다.
