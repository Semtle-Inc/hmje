# 셈테이프 — 자동 미분

셈테이프는 정방향 연산을 기록하고 역순으로 재생하여 등록된 텐서의 기울기를 계산합니다. 각 연산의 미분 구현은 HmjeSem의 학습 연산을 사용합니다. 호출자는 기울기 수식을 직접 연결하는 대신 입력·출력·파라미터와 기울기 버퍼를 등록합니다.

## 구성과 장치

| 구성 요소 | 역할 |
| --- | --- |
| 테이프 | 연산 마디·등록부·역순 재생·기울기 누적 판정 |
| 학습 연산 | 장치별 정방향 및 미분 계산 |
| 호출자 | 저장소·기울기 버퍼·뷰의 수명, 정방향 호출과 Metal 배치 제어 |

첫 기울기 등록 텐서가 CPU 또는 Metal 장치를 정합니다. 텐서와 기울기 텐서의 장치는 같아야 하며 한 테이프에서 장치를 섞을 수 없습니다. CPU와 Metal의 지원 연산은 동일하지 않습니다. CPU 구현이 없는 학습 연산은 거짓을 반환합니다.

기울기 버퍼는 호출자가 준비합니다. 중간 기울기를 자동으로 할당하거나 버퍼의 수명을 연장하지 않습니다. 등록된 버퍼와 정방향에 사용한 데이터는 역전파가 끝날 때까지 유효해야 합니다.

## 호출 순서

1. `셈테이프열기(최대마디수, 최대등록수)`로 테이프를 엽니다.
2. `셈테이프기울기등록(테이프, 텐서, 기울기텐서)`로 필요한 기울기 버퍼를 등록합니다.
3. `셈테이프*` 정방향 연산과 손실 연산을 호출합니다. 각 호출은 즉시 계산하고 역전파 마디를 남깁니다.
4. `셈테이프역전파(테이프)`의 성공 여부를 확인합니다.
5. `셈테이프기울기(테이프, 텐서)`로 기울기 뷰를 읽고 옵티마이저를 실행합니다.
6. 다음 계산에는 `셈테이프비우기`를 사용하고, 사용 종료 시 `셈테이프닫기`를 호출합니다.

테이프 마디의 연산코드는 101 이상입니다. 추론용 기록·재생 그래프와 구분되며 `셈그래프실행`으로 실행할 수 없습니다. 정확한 함수 인자와 반환 타입은 [테이프 구현](../Sources/HmjeSem/tape.hmje)을 참고하십시오.

## 연산과 기울기

| 정방향 API | 계산 및 역전파 |
| --- | --- |
| `셈테이프행렬곱` | `Y = X·Wᵀ`, `dX = dY·W`, `dW = dYᵀ·X` |
| `셈테이프바이어스활성` | 활성 함수의 미분, 바이어스 열합과 선택적 잔차 누적 |
| `셈테이프합성곱전개` | 3×3 im2col과 col2im 역변환 |
| `셈테이프표본브로드캐스트` | 입력 기울기와 표본별 벡터 블록합 |
| `셈테이프소프트맥스교차엔트로피` | 역전파 시 손실 연산을 다시 계산해 로그잇 기울기를 기록 |
| `셈테이프RMS정규화` | 입력과 배율의 기울기; 두 기울기 모두 등록 필요 |
| `셈테이프깊이합성곱` | 인과적 depthwise conv1d의 입력·가중치 기울기 |
| `셈테이프임베딩` | 토큰으로 행 조회, 표의 기울기는 scatter-add; 토큰은 미분하지 않음 |
| `셈테이프마스크교차엔트로피` | 유효 토큰 수로 나눈 평균 손실과 로그잇 기울기 |
| `셈테이프FFT긴합성곱` | FFT 기반 합성곱과 입력·필터 기울기; FFT 길이 최대 4096 |
| `셈테이프사상2` | 더하기·곱하기·GLU·SwiGLU·열배율·시그모이드의 기울기 |

사상2의 방식 번호는 순서대로 0부터 5입니다. 열 조각처럼 보폭이 있는 뷰를 허용하고, 미등록 피연산자의 기울기 계산을 생략합니다. 제자리 연산은 더하기만 허용합니다. FFT 긴 합성곱은 정방향 스펙트럼을 작업 텐서에 보존하여 역전파에서 재사용합니다.

## 초기화와 누적

역전파는 등록된 기울기 버퍼를 해당 장치의 `셈학습채우기`로 0으로 초기화합니다. 손실 마디는 이 초기화 이후 로그잇 기울기를 다시 계산합니다.

각 미분 연산이 쓴 바이트 주소 구간을 기록합니다. 새 출력 구간이 기존 구간과 겹치면 누적하고, 겹치지 않으면 덮어씁니다. 판정은 등록 항목 전체가 아니라 실제 쓰기 구간을 기준으로 합니다. 보폭 뷰는 이를 감싸는 주소 구간으로 판정하므로 보수적으로 누적할 수 있습니다.

열합·블록합·합성곱전개역처럼 누적을 지원하지 않는 미분 연산은 해당 구간의 첫 쓰기여야 합니다. 두 번째 쓰기가 필요하면 역전파가 거짓으로 끝납니다. 실패한 역전파의 기울기를 옵티마이저에 사용하지 마십시오.

## 뷰 등록

등록부는 주소 구간으로 텐서를 찾습니다. 부모 텐서의 구간 안에 있는 열 조각은 같은 보폭의 기울기 뷰로 해석합니다. 같은 메모리를 평탄화한 뷰도 같은 오프셋으로 해석하므로 별도 모양 변경 마디가 필요하지 않습니다. 겹치는 구간의 이중 등록은 거부합니다.

## Beta 1 제한

- 학습 계산은 f32 텐서를 사용하며 토큰·목표 인덱스는 u32입니다. 2차원 이하를 지원하고 심볼릭 차원·고차 미분은 지원하지 않습니다.
- CPU는 활성역·열합·표본브로드캐스트·표본블록합·합성곱전개역·합성곱행렬곱·반행렬곱·SGD걸음의 대응 구현이 없습니다. 해당 경로를 사용하는 테이프 계산은 CPU에서 실패할 수 있습니다.
- 바이어스활성의 입력이 미등록이고 바이어스·잔차만 등록된 경우는 거부합니다.
- RMS정규화는 입력과 배율의 기울기를 모두 등록해야 하며 제자리 연산을 거부합니다.
- 옵티마이저는 테이프 밖에서 실행합니다. AdamW는 파라미터 그룹별 `셈학습Adam걸음`을 사용하며, 걸음 번호는 1부터 시작합니다. 감쇠 마스크와 그룹 정책은 호출자가 결정합니다.

## 검사 소스

[SemTapeTest](../Sources/HmjeSemTapeTest/)에는 명시적 역전파 대조, 유한차분, 등록 겹침·뷰·누적 계약과 CPU·Metal 경로 검사가 포함되어 있습니다. 공개 저장소 루트에서 다음과 같이 빌드합니다.

```sh
hmjec --project libraries/hmje-sem --artifact SemTapeTest --target posix-host-exe -o build/SemTapeTest
```

Metal 검사 실행에는 지원되는 Apple 호스트와 Metal 장치가 필요합니다. 이 개별 검사 산출물은 루트 `tools/test.sh`의 기본 스모크 검사와 별개입니다.
