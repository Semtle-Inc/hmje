# 미러 순환 버퍼

[collections.hmje](../Sources/HmjeSem/collections.hmje)는 고정 바이트폭 행을 위한 범용 순환 버퍼입니다. 저장 공간을
`2 × 용량 × 행바이트`로 잡고 각 쓰기를 원래 슬롯과 한 용량 뒤 슬롯에 함께 기록합니다.
그 결과 순환 경계를 지난 최근 구간도 `미러순환최근조각`이 하나의 연속 `버퍼뷰`로 반환합니다.

- `미러순환필요바이트`: 필요한 저장 바이트 수를 계산합니다.
- `미러순환쓰기`: 전체 순번을 슬롯으로 바꾸어 두 미러 위치에 행 하나를 기록합니다.
- `미러순환최근조각`: 지금까지 쓴 전체 행 수를 받아 최근 `min(누적개수, 용량)`행을 빌립니다.

반환 뷰는 저장 공간을 빌리므로 소유자가 해제하거나 해당 슬롯을 다시 쓰기 전까지만 유효합니다.
이 구조는 LLM 전용이 아니며 슬라이딩 윈도, 스트리밍 신호, 최근 프레임 이력처럼 고정폭 최신
구간을 복사 없이 연속 소비해야 하는 코드에서 사용할 수 있습니다.
