# hmje-sem — 텐서 연산과 자동 미분

CPU·Metal 텐서 연산, 연산 그래프, 중간 메모리 배치와 역전파 테이프를 제공합니다. 모델 추론과 학습 프로그램에서 공통 수치 연산 계층으로 사용합니다.

## 사용

HMJE 1.0.0-beta.1 툴체인의 SDK에 포함됩니다. 소비 프로젝트의 모듈에 사용할 라이브러리를 의존성으로 선언하고, HMJE 소스에서 모듈을 가져옵니다. 내보내는 모듈은 HmjeSem입니다.

```hmjep
모듈 App의
    원본 경로는 "Sources/App"이고,
    의존 라이브러리는 HmjeSem이다.
```

```hmje
HmjeSem을 가져온다.
```

프로젝트·산출물의 전체 구성은 [프로젝트 명세](../../docs/project.md), 이 트리에서 SDK를 빌드·설치하는 절차는 [소스 빌드](../../docs/building.md)를 참고하십시오.

## 기능

| 구분 | 제공 내용 |
| --- | --- |
| 텐서와 저장소 | 자료형·차원·보폭을 검사하는 연산과 비소유 뷰 |
| 연산 그래프 | 고정 버퍼를 재사용하는 기록·재생과 심볼릭 차원 |
| 자동 미분 | 정방향 연산 기록과 등록된 기울기 버퍼의 역전파 |
| 진단 | 할당·복사·Metal 실행·폴백 계수 |

## 지원 범위와 사용 조건

CPU 경로와 Apple 플랫폼의 Metal 경로를 제공합니다. Metal 외부 구현은 macOS·iOS에서 연결됩니다. 지원 연산은 장치별로 다르며, CPU에 대응 구현이 없는 학습 연산은 실패를 반환합니다. 텐서 뷰가 참조하는 저장소와 출력·기울기 버퍼의 수명은 호출자가 관리합니다.
