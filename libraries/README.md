# 공개 라이브러리

HMJE 1.0.0-beta.1 SDK에 포함된 라이브러리입니다. 각 안내에서 내보내는 모듈, 주요 기능, 플랫폼별 제한과 API 문서를 확인할 수 있습니다.

| 라이브러리 | 용도 |
| --- | --- |
| [hmje-sem](hmje-sem/README.md) | 텐서 연산과 자동 미분 |
| [hmje-llm](hmje-llm/README.md) | GGUF 모델과 로컬 텍스트 추론 |
| [hmje-network](hmje-network/README.md) | HTTP와 네트워크 통신 |
| [hmje-realtime](hmje-realtime/README.md) | 이벤트 기반 실시간 통신 |
| [hmje-crypto](hmje-crypto/README.md) | 키 파생과 암호 연산 |
| [hmje-vault](hmje-vault/README.md) | 자격 증명 저장 |
| [hmje-jindo](hmje-jindo/README.md) | 터미널 진행 표시 |
| [hmje-host](hmje-host/README.md) | 파일과 프로세스 호스트 API |
| [hmje-syntax](hmje-syntax/README.md) | HMJE 구문 강조 |
| [hmje-ui](hmje-ui/README.md) | 선언형 화면과 그래픽 |

이 트리의 라이브러리는 [프로젝트 파일](../docs/project.md)의 의존성으로 사용합니다. 정확한 소스 버전은 [SOURCES.md](../SOURCES.md), 설치한 SDK와 공개 소스의 대응·검사 범위는 [공개 준비 상태](../docs/publication-status.md)에 기록합니다.
