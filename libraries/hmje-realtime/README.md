# hmje-realtime — 이벤트 기반 실시간 통신

Engine.IO v4의 WebSocket 전송 위에서 Socket.IO 프로토콜 v5 텍스트 패킷을 처리합니다. HmjeNetwork를 통해 연결하고 JSON 이벤트·확인 응답·재연결 상태를 제공합니다.

## 사용

HMJE 1.0.0-beta.1 툴체인의 SDK에 포함됩니다. 소비 프로젝트의 모듈에 사용할 라이브러리를 의존성으로 선언하고, HMJE 소스에서 모듈을 가져옵니다. 내보내는 모듈은 HmjeRealtime입니다.

```hmjep
모듈 App의
    원본 경로는 "Sources/App"이고,
    의존 라이브러리는 HmjeRealtime이다.
```

```hmje
HmjeRealtime을 가져온다.
```

프로젝트·산출물의 전체 구성은 [프로젝트 명세](../../docs/project.md), 이 트리에서 SDK를 빌드·설치하는 절차는 [소스 빌드](../../docs/building.md)를 참고하십시오.

## 기능

| 구분 | 제공 내용 |
| --- | --- |
| 연결 설정 | URL·네임스페이스·인증·시간 제한 |
| 이벤트 | 이름과 JSON 인자 배열 |
| 확인 응답 | ACK 번호·시간 초과·연결 세대 |
| 재연결 | 지연 상한과 수신 용량 관리 |

## 지원 범위와 사용 조건

연결 하나당 네임스페이스 하나를 사용합니다. 바이너리 첨부 패킷과 polling 전송은 지원하지 않습니다. 기본 설정은 평문 연결을 허용하지 않습니다. 재연결 뒤 데이터 재동기화와 이벤트 중복 처리는 앱의 프로토콜에서 정의합니다. 플랫폼 TLS 조건은 HmjeNetwork를 따릅니다.
