# 클립보드 텍스트

`클립보드텍스트쓰기(텍스트)`는 UTF-8 텍스트를 쓰고 성공 시 바이트 수, 실패 시 음수 호스트 오류를 반환합니다. `클립보드텍스트읽기()`는 `UI클립보드텍스트결과(상태, 텍스트)`를 반환합니다. `상태`는 성공 시 0, 실패 시 음수 호스트 오류이며 빈 클립보드는 빈 문자열로 반환합니다.

macOS는 NSPasteboard, Linux는 X11 선택 영역, Windows는 호스트 클립보드 구현을 사용합니다. 크기 조회와 읽기 사이에 클립보드 내용이 바뀌면 상태 `-34`를 반환하며 호출자가 다시 시도할 수 있습니다.
