# 텍스트입력의 Enter 사건

`텍스트입력의` 안에 `엔터키를 누르면` 블록을 두면 Enter가 현재 값을 추적 저장소에 쓴 뒤 본문을 실행합니다. 줄바꿈은 넣지 않습니다. Shift+Enter는 여러줄 입력에서 줄바꿈을 넣고 단일줄 입력에서는 무시합니다. 블록이 없으면 기존 동작을 유지합니다.

```hmje
텍스트입력의
    값은 입력글이고,
    여러줄은 참이고,
    엔터키를 누르면
        메시지보내기를 (글: 입력글)로 실행한다.
        입력글은 ""이다.
```

한국어·일본어 IME 조합을 확정하는 Enter는 조합만 확정합니다. 다음 Enter부터 본문을 실행합니다. macOS·iOS return 키·Windows·Linux와 IDE 미리보기에서 같은 계약을 사용합니다. 함수로 만든 입력에는 `UI텍스트입력엔터지정(입력, 식별자)`로 텍스트 사건의 식별자를 연결합니다.
