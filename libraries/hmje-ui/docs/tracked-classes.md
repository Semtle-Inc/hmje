# 추적되는 클래스와 화면 기억

타입·필드·저장·함수 수식어의 언어 계약은 [언어 명세](../../../docs/language.md)에 정의되어 있습니다. 이 문서는 [상태 추적 구현](../Sources/HmjeUI/ui/ui_tracking.hmje)의 읽기 기록과 화면 재구성·기억 동작을 설명합니다. HMJE 1.0.0-beta.1 툴체인을 사용합니다.

## 선언

```hmje
공개 타입 수식어 추적의
    활용은 되다이고,
    스레드는 UI 전용이다.
    필드를 읽을 때
        추적필드읽음을 (객체, 필드)로 실행한다.
    필드를 쓸 때
        추적필드바뀜을 (객체, 필드)로 실행한다.
    끝날 때
        추적객체끝남을 (객체)로 실행한다.
```

`Sources/HmjeUIDesktop/window_modifiers.hmje`는 창 문장이 읽을 화면 필드 수식어
`창을 구분하는`·`창 제목이 되는`을 선언합니다(훅 없음, 표지만).

## 읽음 기록과 다시 짓기

- 열쇠 = (객체 주소, 필드 번호)를 섞은 64비트 값. 추적 대상 상자는 (상자 주소, 상자 칸),
  객체의 사라짐은 (객체 주소, 사라짐 칸)입니다.
- 읽음 표는 열린 주소법 표(칸 = 열쇠·창·세대)입니다. 창마다 빌드를 시작할 때 세대를 올리므로
  지난 빌드의 기록은 지우지 않아도 사라집니다. 짓는 동안(`UI상태빌드중`)이나 기억 틀 안에서만
  적습니다.
- 쓰기(`추적필드바뀜`)는 그 열쇠를 읽은 창만 다시 짓게 합니다: 지금 창은 `추적대상더러움`,
  다른 창은 대기 더러움(앱 루프가 프레임 처음에 `추적창대기더러움꺼내기`로 봅니다). 바뀐
  (열쇠, 창)은 그 창의 다음 빌드가 끝날 때까지 남아 화면 기억을 무효로 합니다.
- 추적을 안 쓰는 앱은 아무것도 할당하지 않습니다(창 표는 첫 추적 읽기·첫 화면 기억에서 생깁니다).

## 화면 기억

컴파일러는 받은 값을 지문으로 섞을 수 있는 **모든 화면**을 `<화면>기억그리기`로 변환합니다. 추적 대상을 쓰면 그 상자를 읽은 화면(과 조상)만 다시 돌고, 받은
값이 같은 자식·형제는 되살립니다. 그리는 내용이 모듈 전역 변수를 바로 읽는 화면은
`UI화면기억불가()`로 자기·조상의 기억을 막습니다.

```
부른경로 = UI상태현재경로()
지문 = 받은 값들을 섞은 값
칸 = UI화면기억찾기(__상태경로, 지문)
칸 ≠ 0 → UI화면기억되살리기(칸), UI상태경로복원(부른경로)
그 밖   → UI화면기억시작 → UI화면기억입력객체(받은 객체…) → <화면>그리는내용 → UI화면기억끝
```

- **일지.** 기억 틀이 열려 있는 동안 트리 밖의 흔적을 적습니다: 상태 상자 방문(1),
  경로 세대 갱신(2), 디스패치 표 넣기(3), 비동기 작업 방문(4), 지연 컨테이너 보호(5),
  안쪽 기억 칸(6 — 조상이 되살아날 때 그 아래 칸도 이번 빌드에 쓴 것으로 적습니다).
  되살릴 때 다시 남겨 세대 정리·디스패치 거르기·작업 수명이 트리를 새로 지은 것과 같게 봅니다.
  안쪽 틀의 흔적은 바깥 틀의 흔적이기도 합니다(틀들이 한 줄을 나눠 씁니다).
- **의존.** 틀 안에서 읽은 추적 필드·상자·받은 객체의 사라짐 열쇠. 되살릴 때 읽음 표와
  바깥 틀에 다시 적습니다.
- **무효.** 지문이 다름, 의존 열쇠가 바뀜, 바로 앞 빌드에서 쓰지 않음(그 사이 상태 상자가
  수거됐을 수 있습니다), `UI화면기억무효요청`(추적되지 않는 까닭의 재구축 — 앱 루프의 테마·크기·
  스크롤·텍스트 세션·네비게이션 자리, `추적대상더럽히기`), 짓는 동안 `UI화면기억불가`
  (애니메이션 값·지연 컨테이너·기준 스크롤을 읽음).
- **저장.** 칸은 평행 배열이고 (창, 경로) 해시 색인으로 찾습니다. 일지·의존은 두 평평한 풀 안의
  [시작, 길이)입니다. 빌드가 끝나면 이번에 쓰지 않은 칸을 버리며 풀을 새로 담습니다(버릴 칸이 없고
  죽은 조각이 적으면 건너뜁니다).
- 창을 닫으면(`UI창문맥치우기`) 그 창의 칸을 버립니다. 마지막 창이면 표를 모두 놓습니다.

## 저장 수식어와 함수 수식어

`추적 대상`·`외부 추적 대상`은 `ui_storage_rules.hmje`의 **저장 수식어** 선언입니다(툴체인
`language.md` 「저장 수식어」). 저장소 `추적칸`은 상태 칸 표에 매인 힙 칸에 원소 하나짜리 배열을
담고, 읽기·쓰기가 위의 `추적상자읽음`/`추적상자바뀜`을 부릅니다. 같은 파일의 **함수 수식어**
`그리는`이 화면을 놓는 자리마다 상태 경로 한 칸을 깝니다(`화면문맥진입`/`화면문맥복원`, 호출 자리
열쇠 `자리표`). 컴파일러는 각 선언에 정의된 훅을 전개합니다.
