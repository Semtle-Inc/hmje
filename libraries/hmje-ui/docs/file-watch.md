# 파일과 디렉터리 감시

`UI파일감시시작(루트, 제외패턴, 합침밀리초)`는 UTF-8 절대 디렉터리 경로에서 재귀 감시를 시작합니다. 성공 시 양수 핸들, 실패 시 음수 호스트 오류를 반환합니다.

작업 트리 감시에서 `.git`을 제외하더라도 HEAD·참조·인덱스 변경을 받으려면 `.git`을 루트로 별도의 감시를 시작합니다. 네이티브 백엔드는 상대 경로와 개별 경로 구성 요소에 제외 패턴을 적용합니다. `node_modules`와 `build`는 해당 디렉터리 트리를 제외합니다.

## 사건 수신과 종료

`UI파일감시기다리기(handle)`는 비동기 함수이며 `기다린 결과`로 결과를 받습니다. 반환값은 `UI감시결과(상태, 사건들)`입니다. 상태 1은 합쳐진 사건 배열, 0은 감시 종료, 음수는 호스트 오류를 뜻합니다.

각 `UI감시사건`은 절대 경로와 `종류`를 포함합니다.

| 종류 | 의미 |
| ---: | --- |
| 1 | 생성 |
| 2 | 수정 |
| 3 | 삭제 |
| 4 | 이름 변경 |

이름 변경 사건은 영향을 받은 경로를 보고하며 이전·새 경로의 쌍을 보장하지 않습니다. `UI파일감시꺼내기`는 기다리지 않고 준비된 사건을 꺼냅니다. 대기 작업이 끝난 뒤 `UI파일감시중지(handle)`를 호출합니다. 감시 하나당 대기 작업 하나를 지원합니다.

## 플랫폼 구현

macOS는 디스패치 큐에서 FSEvents 파일 사건을 사용합니다. Linux는 재귀 inotify 감시를 사용하며 새로 생성한 디렉터리도 추가합니다. 두 구현은 네이티브 코드에서 제외 패턴을 적용하고 운영체제 사건으로 비동기 작업을 깨웁니다.

macOS는 심볼릭 링크 경로를 정규화할 수 있습니다. 예를 들어 `/tmp`가 `/private/tmp`로 반환될 수 있습니다. Windows는 재귀 overlapped `ReadDirectoryChangesW`를 사용하고 `/` 구분자의 UTF-8 절대 경로를 반환합니다. 모바일 대상은 미지원 상태 `-120`을 반환합니다.
