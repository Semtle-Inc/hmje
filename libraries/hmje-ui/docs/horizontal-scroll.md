# 가로스크롤영역

`가로스크롤영역`은 한 줄로 늘어선 내용(탭 줄·칩 줄)이 폭을 넘칠 때 옆으로 미는 블록입니다
구현은 `Sources/HmjeUI/ui/ui_hscroll.hmje`.

```hmje
가로스크롤영역의
    식별자는 7301이고,
    간격은 6이고,
    정렬은 가운데이고,
    보일항목은 지금탭번호이고,
    너비는 가능한 최대이고,
    내용은
        탭들의 각 탭에 대해 탭의 번호로 식별하며
            탭단추의
                탭은 탭이다.
```

- 내용은 한 줄 `수평배치`로 자연 폭에 놓이고, 영역 밖은 그리기에서 잘리며 히트 테스트에서도
  빠집니다(잘린 항목이 옆 단추 대신 눌리지 않습니다).
- `식별자`(0 아님)가 오프셋 기록의 열쇠입니다. 트리를 다시 만들어도 위치가 남습니다.
- `보일항목`(내용 자식 번호, 0부터)이 **바뀌면** 그 항목이 보이도록 최소한만 밉니다(이웃 항목 24pt
  여유). 같은 값으로 다시 만들면 사용자가 민 자리를 지킵니다.
- 입력: 정밀 가로 델타(트랙패드 두 손가락 옆 쓸기, macOS 시프트+휠)를 받습니다. 세로 휠·세로 델타는
  이 영역이 세로 `스크롤영역` 안에 있지 않을 때만 가로로 바꿔 받습니다(목록 속 캐러셀의 세로 휠은
  바깥 목록 몫).
- 앱은 `가로스크롤상태읽기(식별자)`로 현재/최대 오프셋·창 너비를 읽어 넘침 표시(꺾쇠 단추 등)를
  그리고, `가로스크롤이동(식별자, 증분)`으로 밉니다. 상태를 읽은 기록은 배치가 값을 바꾸면 트리를 한 번
  더 만들어 표시가 새 값을 따릅니다.
