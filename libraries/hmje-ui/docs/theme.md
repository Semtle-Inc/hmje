# 테마 (Theme)

HmjeUI는 스타일 없는 기본 요소와 중립 기본 테마를 제공합니다. 버튼·입력 프리셋,
토글·체크박스·슬라이더·선택 항목·아이콘은 별도 디자인 시스템의 일반 화면입니다.
HmjeUI 기본 요소는 현재 위치의 `물려받은` 유산을 읽습니다.

## 공개 유산과 기본값

| 이름 | 타입 | 기본값 |
| --- | --- | --- |
| `디자인토큰` | `UI테마` | `기본UI테마()` |
| `글꼴` | `시스템폰트종류` | Pretendard |
| `기본칠` | `UI칠` | `UI칠없음()` |
| `강조칠` | `UI칠` | `UI칠없음()` |
| `테마` | `시스템테마종류` | 시스템 라이트/다크 |
| `글자모드` | `글자모드종류` | 일반 |
| `기기` | `디바이스종류` | 자동 |

기본 테마에는 중립 역할색과 공개 색 낱말과 색 스타일이 들어 있습니다. 파랑·빨강 등
유채색의 500 단계는 별도 디자인 시스템을 가져오지 않아도 사용할 수 있습니다.
글자 스타일·효과·치수 질문도 기본 테마가 답합니다. 기본 버튼과 입력에는 스타일·크기
프리셋이 없습니다. 아이콘 이름·폰트·코드표는 포함하지 않으며 `UI테마`에는 폰트 훅만 남습니다.

글꼴(Pretendard·SUITE·Montserrat·D2Coding·Noto Color Emoji)의 라이선스는
[폰트 자원](../assets/fonts/)의 `*-LICENSE.txt`에 있습니다.

## 테마 값 전달

기존 노드의 `물려주는` 블록으로 테마 값을 전달합니다. 더 깊은 노드에서 다른 값을
전달하면 그 서브트리만 바뀝니다. 다른 창과 형제 노드의 유산은 바뀌지 않습니다.

다음은 앱에서 정의한 `첫화면`에 테마를 전달하는 코드 조각입니다.

```hmje
HmjeUI를 가져온다.

함수 내색값은 (토큰: 자연수, 브랜드: 자연수, 테마: 자연수, 뉴트럴: 자연수)를 받아
    만약 토큰 == 자연수(시스템색상종류의 강조채움)이면
        자연수32(0xff7a3cf0)을 자연수32로 반환한다.
    기본테마색값(토큰, 브랜드, 테마, 뉴트럴)을 자연수32로 반환한다.

함수 보라디자인토큰은
    상수 기본은 기본UI테마()이고, UI테마이다.
    UI테마(기본에서, 이름: "보라", 색값: 내색값)를 UI테마로 반환한다.

화면을 표시하는 함수 앱시작은
    그리는 내용은
        첫화면의
            물려주는
                디자인토큰은 보라디자인토큰()이다.
```

`UI테마설치`는 폐기 예정 호환 함수이며 설치 작업을 하지 않습니다. 경고가 안내하는
위 노드 형태로 바꿉니다. 전역 설치 테이블이나 설치번호를 렌더링에 사용하지 않습니다.

## UI테마 처리 함수

함수 필드는 숫자 인자를 받고 값을 돌려줍니다. 기본 테마에서 필요한 필드만 바꾸면 됩니다.

| 필드 | 받는 것 → 돌려주는 것 |
| --- | --- |
| `색값` | (토큰, 브랜드, 테마, 뉴트럴) → 0xAARRGGBB |
| `토큰정규` | 역할 번호 → 테마 토큰 번호 |
| `눌림토큰` | 호버 칠 토큰 → 눌림 칠 토큰 |
| `색낱말토큰` | (색어휘, 색스타일) → 토큰 |
| `토큰스타일토큰` | (토큰, 색스타일) → 같은 색 무리의 스타일 토큰 |
| `버튼칠토큰` | (스타일 번호, 색 번호, 부분 번호) → 토큰; 디자인 시스템이 사용 |
| `글자값` | (글자 스타일, 글자모드, 글자 항목) → 값 |
| `치수` | (치수 항목, 크기 번호, 글자모드, 기기) → 값 |
| `효과값` | (효과 항목, 프리셋) → 값 |
| `아이콘폰트자원` | 폰트 자원 이름; 기본 테마는 빈 문자열 |
| `아이콘코드` | (아이콘 번호, 채움 0/1) → 코드포인트 |
| `아이콘정규` | 아이콘 번호 → 테마 아이콘 번호 |

HmjeUI 역할 번호는 1,000,001부터입니다. 기본 색 낱말은
`1,200,000 + 낱말 × 1000 + 스타일` 영역을 사용합니다. 별도 테마의 고유 토큰은
1..999,999 영역을 쓸 수 있습니다. 라이트/다크 번호는 1/2이며 브랜드와 뉴트럴 축의
뜻은 제공자가 정합니다.

## 기억과 변경

화면 기억은 켜져 있습니다. 읽은 유산 값이 바뀔 때 해당 화면을 다시 구성합니다.
함수 필드는 코드 포인터와 캡처 환경의 동일성으로 비교합니다. 캡처한 가변 상태만
바꾸고 같은 `UI테마` 값을 재사용하면 변경을 알아낼 수 없습니다. 제공자는 그 상태가
바뀔 때 새 `UI테마` 값을 만들어 전달해야 합니다.

역할·색 낱말은 노드가 유지한 토큰을 서브트리 환경의 디자인토큰과 테마로 풉니다.
글자·치수 등 구성 값은 그 유산을 읽은 화면이 다시 구성하면서 바뀝니다.

## 색 낱말과 디자인 시스템

HmjeUI의 공개 색 그룹은 빨강, 주황, 노랑, 초록, 틸, 하늘, 파랑, 인디고, 보라, 로즈, 회색, 검정, 흰색의 13개입니다. 역할 이름과 `색상스타일` API로 색을 지정합니다.

앱의 테마는 `UI테마` 처리 함수로 팔레트와 역할색을 확장할 수 있습니다. 별도 테마를 사용하는 서브트리에 `디자인토큰`을 전달합니다.

색상 노드는 낱말과 스타일을 보관하고 그 하위 트리의 디자인토큰 및 라이트/다크 테마에 따라 렌더링 시점에 해석합니다. 부모와 다른 디자인 시스템을 `물려주는` 하위 트리에 전달할 수 있습니다.

## 회색과 색 스타일

회색도 일반 색 그룹이며 `연함`·`채움호버`·`채움눌림`·`글자본문`·`테두리` 등 기존 색 스타일을 지원합니다. 회색 스타일은 HmjeUI의 중립 팔레트로 해석합니다. 이미 정의된 회색의 레이아웃 스타일(채움·글자·배경페이지·배경계층2·배경패널·가라앉음·글자약함·글자연함·글자진한면위·글자진한면위약함·선기본·선연함·선강함·배경가라앉음)은 이전 역할 토큰을 유지합니다. 기존 앱의 해당 픽셀을 바꾸지 않기 위한 호환 규칙입니다.

113개 색 스타일 중 일반 색 그룹에는 99개가 정의되어 있습니다. 레이아웃/표면 역할 전용인 배경패널·돋움·가라앉음·패널·기본·글자약함·글자연함·선기본·선연함·선강함·배경가라앉음·글자진한면위약함·돋움반전·오버레이는 일반 색 그룹 조합에 쓰지 않습니다. 회색은 위 호환 규칙에 해당하는 9개를 추가로 지원하므로 108개입니다. 고정 색 낱말과 미지원 스타일을 노드에 함께 쓰면 원본 파일·줄 번호를 포함한 컴파일 오류입니다.
