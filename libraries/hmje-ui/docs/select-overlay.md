# 드롭다운 목록 오버레이

`텍스트입력의 모드는 선택`의 목록은 배치 트리 밖에서 앱 루프가 맨 위에 그리는 오버레입니다 — 다른
행을 밀거나 사이에 끼지 않습니다. 자리와 동작은 `Sources/HmjeUI/ui/ui_select_list.hmje`가 정합니다.

- 입력 본체(앵커) 바로 아래에 펴고, 아래 공간이 모자라고 위가 더 넓으면 위로 폅니다. 창 안에 들어오게
  가로로 밉니다. 너비는 앵커 이상, 항목 글(+설명)이 들어갈 만큼(최대 420pt).
- 최대 8행이 보이고 넘치면 창처럼 굴립니다: 열 때 지금 값이 보이게, 방향키 강조가 밖으로 나가면 따라,
  목록 위 휠·트랙패드로. 오른쪽에 위치 막대.
- 바깥 누르기·탈출로 닫고, 위/아래·엔터/공백으로 고릅니다. ⌘/Ctrl 조합 키는 앱 단축키로 넘깁니다(드롭다운에
  초점이 있어도 ⌘S가 먹습니다).
- `선택항목의 설명은 "…"` — 행 오른쪽의 흐린 보조 글(닫힌 입력에는 내용만).
