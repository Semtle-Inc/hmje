# 비동기 이미지

`비동기이미지`는 URL 요청, JPEG/PNG 디코드, 디코드 결과 캐시, 화면 수명에 따른 작업 취소를 한 컴포넌트로 묶습니다. 앱은 네트워크 응답 바이트나 임시 이미지 키를 직접 관리하지 않습니다.

다음은 앱이 정의한 `장소`, `이미지스켈레톤`, `이미지오류화면`을 사용하는 화면 코드 조각입니다.

```hmje
비동기이미지의
    내용은 장소.이미지URL이고,
    맞춤은 채우기이고,
    반경은 16이고,
    너비는 가능한 최대이고,
    높이는 188이고,
    로딩 중 내용은
        이미지스켈레톤이다.
    실패 시 내용은
        이미지오류화면이다.
```

- `내용`은 이미지 URL입니다. HTTPS가 기본이며 리다이렉트는 최대 5회 따릅니다.
- `로딩 중 내용`과 `실패 시 내용`은 각각 하나의 루트 화면을 받습니다. 생략하면 빈 화면입니다.
- `맞춤`, `반경`, 너비·높이 제약은 일반 `이미지`와 같습니다.
- 같은 URL의 디코드 결과는 URL 해시 자산 키로 재사용합니다. 화면이 사라지면 진행 중인 작업은 HmjeUI 비동기 작업 수명에 따라 취소됩니다.
- 현재 네트워크 바이트 디코드는 JPEG와 PNG를 지원합니다. 지원하지 않는 형식이나 HTTP 실패는 `실패 시 내용`으로 전환합니다.
