# hmje-crypto — 키 파생과 암호 연산

PBKDF2-HMAC-SHA256 키 파생, P-256 키 검사·생성·비밀 합의, 운영체제 안전 난수와 메모리 지우기 API를 제공합니다.

## 사용

HMJE 1.0.0-beta.1 툴체인의 SDK에 포함됩니다. 소비 프로젝트의 모듈에 사용할 라이브러리를 의존성으로 선언하고, HMJE 소스에서 모듈을 가져옵니다. 내보내는 모듈은 HmjeCrypto입니다.

```hmjep
모듈 App의
    원본 경로는 "Sources/App"이고,
    의존 라이브러리는 HmjeCrypto이다.
```

```hmje
HmjeCrypto를 가져온다.
```

프로젝트·산출물의 전체 구성은 [프로젝트 명세](../../docs/project.md), 이 트리에서 SDK를 빌드·설치하는 절차는 [소스 빌드](../../docs/building.md)를 참고하십시오.

## 기능

| 구분 | 제공 내용 |
| --- | --- |
| 키 파생 | PBKDF2SHA256파생 |
| P-256 | P256공개키검사·P256키쌍검사·P256키쌍만들기·P256비밀합의 |
| 난수 | 암호안전난수채우기 |
| 결과와 메모리 | 암호연산결과·암호메모리지우기 |

## 지원 범위와 사용 조건

P-256은 Apple·Android·Windows 구현을 연결하며, Linux에서는 미지원 결과를 반환합니다. PBKDF2와 안전 난수의 지원 범위는 별도로 구성됩니다. 주소를 받는 위험 API는 호출자가 유효한 버퍼와 용량을 보장해야 합니다. 비밀번호·소금은 원시 바이트이며 문자열 정규화나 기본 반복 횟수를 적용하지 않습니다. 키 저장·nonce 재사용 방지·프로토콜 구성은 앱에서 담당합니다.
