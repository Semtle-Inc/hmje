[공개 소스 빌드 검증 기록](source-sync-verification.json)은 소스 기준·빌드 커밋·도구 해시·검사 목록을 기록합니다. 검증 기록은 기록된 소스 빌드 커밋을 대상으로 합니다. 이후의 공개 문서 편집은 실행 소스와 검증 입력을 변경하지 않습니다. 공개용 경로와 진단 안내의 조정은 [소스 출처](../SOURCES.md)를 참조하십시오.

UI 예제는 앱 빌드를 확인했습니다. UI 입력·화면 표시, Windows·Linux 실행, 모바일 배포, 외부 모델 추론은 이번 검증 대상이 아닙니다. 공개 소스 빌드의 결과를 서명된 배포 원본과의 전체 바이트 일치로 표현하지 않습니다.

## 공개 문서 검토

2026-10-09 공개 문서 검토에서 Release 기반 소스 빌드와 [Swift 씨앗 부트스트랩](bootstrap.md)을 구분하고, [라이브러리 안내](../libraries/README.md)에 모듈·기능·플랫폼별 조건을 보완했습니다. API 문서는 현재 구현을 기준으로 정리하고 공개 트리에 없는 문서·검사 명령 참조를 수정했습니다.

상대 문서 링크와 Git 변경 형식을 검사했습니다. 새 안내의 `SemTapeTest`와 `GemmaStream` 빌드 명령은 macOS ARM64에서 컴파일을 확인했고, `SemTapeTest`의 22개 검사는 모두 통과했습니다. `GemmaStream`은 모델 실행을 검증하지 않았습니다. 개발자 세션의 예제 83개 해시와 Swift 씨앗의 입력 해시는 유지됩니다.

## 배포 연결

현재 로컬 저장소에는 원격 저장소가 설정되지 않았습니다. 실제 공개 위치와 다운로드 자산을 연결한 뒤 설치 안내와 다운로드 링크를 확인해야 합니다.

개발자 세션 예제의 MIT License는 컴파일러·런타임 라이선스와 별개입니다. Swift 씨앗 저장소에는 동일한 버전 1.0의 컴파일러·런타임 라이선스가 포함됩니다.
