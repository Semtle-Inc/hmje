# 공개 플랫폼 라이브러리

이 모노레포의 `libraries/`에는 Beta 1의 공개 라이브러리 10개가 있습니다.
`SOURCES.md`는 원본 커밋을, `platform-libraries.lock`과 `libraries/index.tsv`는
설치에 사용되는 정확한 소스 목록을 기록합니다. 빌드 시 두 목록이 맞는지
검사하고 로컬 소스를 사용하므로 별도 원격 저장소가 필요하지 않습니다.

설치한 툴체인은 이 소스를 `lib/hmje/platform-libraries/`에 싣습니다.
프로젝트에서는 `의존 라이브러리`를 선언하고 HMJE 모듈 이름으로 가져옵니다.
공개 UI 모듈 이름은 `HmjeUI`입니다.
표준 라이브러리는 암시적으로 불러오고, 기반·운영체제·SQLite·Backend 등은
사용하는 모듈을 명시적으로 가져옵니다.

오디오, 내부 디자인 시스템, 내부 데이터베이스 엔진과 내부 SDK는 포함하지
않습니다. 파일·프로세스 및 구문 강조 라이브러리만 IDE 원본의 지정된 공개
하위 폴더에서 내보냈으며 IDE 본체 소스는 없습니다.
