# 표준·런타임 라이브러리

HMJE 프로그램의 기본 어휘와 운영체제 경계, 데이터베이스·서버 API를 제공합니다. 모듈과 대상별 네이티브 연결은 [Project.hmjep](Project.hmjep)에 정의되어 있습니다.

## 제공 모듈

| 모듈 | 기능 |
| --- | --- |
| `표준` | 문자열·숫자·배열·출력 등 프로그램의 기본 어휘 |
| `기반` | 암호·코덱·통신·수학과 공통 자료 구조 |
| `운영체제` | 창·입력·표면 등 플랫폼 계약 |
| `DB` | 타입 있는 관계형 질의·스키마와 데이터베이스 공통 모형 |
| `DBAsyncWire` | 비동기 데이터베이스 연결을 위한 공통 경계 |
| `SQLite` | 포함된 SQLite 엔진의 동기 API |
| `SQLiteAsync` | SQLite 비동기 연결과 작업 실행 |
| `Backend` | HTTP 서버·라우팅 |

## 사용과 플랫폼

`표준`의 기본 어휘는 암시적으로 제공됩니다. 그 밖의 모듈은 소비 프로젝트의 의존 라이브러리로 선언하고 소스에서 가져옵니다. [프로젝트 명세](../docs/project.md)와 [언어 명세](../docs/language.md)를 참고하십시오.

파일·소켓·프로세스·환경과 창·입력 기능은 운영체제별 구현을 연결합니다. 대상별 지원 기능·권한·실행 환경은 서로 다를 수 있습니다. DB의 SQL 방언 처리와 실제 연결 어댑터는 별개이며, 이 배포에 포함된 데이터베이스 엔진은 SQLite입니다.
